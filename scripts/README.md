# Scripts

Development and maintenance utilities for NOTA.

| Script | Purpose |
|---|---|
| `seed.ts` | Inject realistic local demo data (Tangerang/BSD merchants) into the local SQLite database via the Settings screen |
| `verify-bundle.js` | Inspect the Expo production bundle to verify no API keys are leaked in the JS output |

## Usage

These scripts are dev-only tools. They are not part of the app bundle.
